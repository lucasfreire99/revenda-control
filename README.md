# 🛍️ Revenda+ | Controle Financeiro

Sistema web para controlar produtos, estoque, vendas e lucro de revenda. Inclui dashboard financeiro, gráfico mensal, filtros e exportação de relatórios para Excel.

## ✨ Recursos

- Cadastro de produtos por categoria e quantidade, com “Perfumaria” predefinida
- Categorias disponíveis: Perfumaria, Body Splash, Body Care / Corpo, Skincare, Make / Maquiagem, Hair / Cabelos, Desodorantes, Bath & Body, Kits, WeHot, Linha Sensual, Power Shock e Infantil
- Dashboard com total investido, vendido e lucro
- Gráfico mensal de desempenho
- Marcação de vendas com atualização automática
- Filtros por mês e categoria, com opção para exibir todas as categorias
- Exportação de relatórios em Excel (`.xlsx`) com abas de resumo e produtos; os filtros ativos são aplicados ao relatório
- Modo dark/light com persistência
- Dados dos produtos e preferências salvos no navegador

## ▶️ Como usar

Abra o `index.html` em um navegador moderno. Não é necessário instalar ou iniciar um servidor. É preciso ter conexão com a internet para carregar as bibliotecas Chart.js e SheetJS, usadas pelo gráfico e pela exportação para Excel.
